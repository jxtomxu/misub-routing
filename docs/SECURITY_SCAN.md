# 敏感信息扫描

项目只从脱敏参考材料提取公开规则 URL 和公开业务规则；没有复制参考配置中的节点、私人规则占位值或任何实际 MiSub 订阅。自建节点、私人域名、私人 Host 与订阅凭据留在设备本地。

`./scripts/validate` 执行 `scripts/scan-secrets.py`，扫描拟交付的文本文件，检查常见 GitHub token、私钥头、URL 凭据、常见带认证参数的 URL 和 JWT 形式。扫描只打印文件名、行号和类型，不打印匹配值。`.gitignore` 排除 `local/` 内非示例文件、`.env`、`*.local.*` 与本地环境。

扫描是特征匹配，无法识别所有私人域名、IP、节点格式或新型密钥；不能把它当成无泄露的数学证明。公开上游和规则中出现的公网地址、标准 LAN 网段及文档中的 `example` 保留域仅为规则或测试数据，不代表实际私人配置。提交前仍应检查暂存文件和变更内容。

扫描还检查 UUID 格式和常见代理节点 URI。3 条含 UUID 格式域名的公开上游规则已从可发布缓存和产物中排除；这不是发现了用户凭据，具体数量记录在 `sources/cache/_omitted.json`。
